# Pennywise — Expense Tracker

A responsive personal expense tracker built with HTML, CSS and vanilla JavaScript.

## Features
- Add expenses with a name, amount, category and date
- View recent transactions
- Delete an expense
- See total expenses, transaction count and average expense
- View category-wise spending breakdown
- Save entries in browser `localStorage`
- Responsive layout for mobile and desktop

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

No build tools or installation required.

## Data note
Expenses are saved in the browser's local storage on the device/browser where you use the app. Clearing browser data may remove them.
